# คู่มือโค้ดเว็บไซต์ Indigo Pool Villa

เอกสารนี้อธิบายว่าไฟล์และส่วนสำคัญของเว็บไซต์ทำหน้าที่อะไร รวมถึงจุดที่ใช้ปรับเนื้อหาและรูปแบบภายหลัง เว็บไซต์นี้เป็นเว็บแบบ Static ที่สร้างด้วย HTML, CSS และ JavaScript โดยไม่ต้องติดตั้ง framework เพิ่ม

## ภาพรวมไฟล์

- `index.html` — หน้าแรกและเนื้อหา เช่น เมนู บ้านพัก ราคา และช่องทางติดต่อ
- `amenities.html` — หน้าสิ่งอำนวยความสะดวก พร้อมข้อมูลสองภาษาและรายละเอียดแยกตามหมวด
- `styles.css` — สี ฟอนต์ ระยะห่าง รูปแบบการ์ด และการจัดหน้าให้รองรับมือถือ
- `script.js` — การสลับภาษา เมนูมือถือ ปีที่แสดงในลิขสิทธิ์ และหน้าต่างดูรูปประกาศ
- `assets/` — รูปภาพที่เว็บไซต์เรียกใช้ เช่น โลโก้ ภาพหน้าแรก และภาพประกอบการ์ดบ้านพัก
- `p1.jpg`, `p2.jpg`, `p3.jpg` — ภาพประกาศฉบับเต็มของบ้าน A-215, B-216 และ C-217 ที่เปิดดูจากการ์ดได้

## อธิบาย `index.html`

### ส่วน `<head>`

กำหนดข้อมูลพื้นฐานของหน้าเว็บ เช่น ภาษาเริ่มต้นเป็นไทย (`lang="th"`), การรองรับจอมือถือ, ชื่อหน้าเว็บ, คำอธิบายสำหรับผลค้นหา และข้อมูลเวลานำลิงก์ไปแชร์บนโซเชียล

เว็บโหลดฟอนต์ **Anuphan** และ **DM Sans** จาก Google Fonts แล้วเชื่อม `styles.css` เพื่อจัดหน้าตา การโหลดฟอนต์จาก Google ต้องมีอินเทอร์เน็ต หากโหลดไม่ได้ เบราว์เซอร์จะใช้ฟอนต์สำรอง

### แถบเมนู `<header class="topbar">`

- โลโก้ใช้รูป `assets/indigo-logo.png` และกดเพื่อกลับไปส่วนบนสุด
- เมนูนำทางพาไปยังส่วนบ้านพัก (`#villas`), สิ่งอำนวยความสะดวก (`#experience`) และติดต่อ (`#contact`)
- ปุ่มภาษาเรียก `langSwitch` เพื่อเปลี่ยนเนื้อหาระหว่างไทยกับอังกฤษ
- ปุ่มเมนูมือถือเรียก `menuToggle` เพื่อเปิดหรือปิดเมนูบนจอเล็ก

### ส่วนหน้าแรก `<section class="hero" id="home">`

เป็นแบนเนอร์หลักของเว็บ ภาพพื้นหลังมาจาก `assets/home-pool.jpg` ส่วน `hero-shade` เป็นชั้นสีเข้มโปร่งใสที่ช่วยให้ตัวอักษรสีขาวอ่านง่าย เนื้อหาหัวข้อและคำโปรยอยู่ใน `hero-content`

### ส่วนแนะนำ `<section id="experience">`

ข้อความแนะนำประสบการณ์การพัก ใช้เป็นจุดหมายของเมนู “สิ่งอำนวยความสะดวก” และเป็นส่วนเกริ่นก่อนรายการบ้านพัก

### รายการบ้านพัก `<section id="villas">`

มีการ์ด 3 หลัง ได้แก่ A-215, B-216 และ C-217 แต่ละการ์ดประกอบด้วยรหัสบ้าน จำนวนห้องนอน ห้องน้ำ จำนวนผู้เข้าพัก ราคา คำอธิบาย และปุ่มเปิดภาพประกาศเต็ม

การ์ดใช้คลาส `image-a`, `image-b`, `image-c` เพื่อจับคู่กับรูปปกใน `assets/` ส่วน `data-poster` ระบุไฟล์ภาพประกาศเต็มที่ JavaScript เปิดในหน้าต่างขยาย

### สิ่งอำนวยความสะดวก `<section class="amenities">`

จัดภาพและข้อความคู่กัน อธิบายสระว่ายน้ำ ครัว และกิจกรรมต่าง ๆ ป้ายอย่าง `PRIVATE POOL` และ `KARAOKE` เป็นข้อความประกอบการนำเสนอ

### ข้อมูลก่อนเข้าพัก `<section class="stay-notes">`

แสดงเวลาเช็กอิน/เช็กเอาต์ เงินประกัน และเงื่อนไขการจอง เป็นข้อความประกอบการตัดสินใจ

### ส่วนจองและติดต่อ `<section id="contact">`

- ปุ่ม LINE เปิดบัญชี `@indigovilla`
- ปุ่มโทรศัพท์ใช้ลิงก์ `tel:` สำหรับเริ่มโทรบนอุปกรณ์ที่รองรับ
- หมายเหตุราคาแจ้งว่าราคาถอดจากภาพประกาศ และให้ตรวจสอบราคา/วันว่างล่าสุดก่อนจอง

เว็บไซต์ปัจจุบัน **ยังไม่มีระบบเช็กวันว่าง ชำระเงิน หรือบันทึกการจองอัตโนมัติ** ลูกค้าติดต่อผ่าน LINE หรือโทรศัพท์โดยตรง

### ท้ายเว็บและหน้าต่างรูป

Footer แสดงโลโก้และข้อความลิขสิทธิ์ ส่วน `posterModal` เป็นกล่องแสดงภาพประกาศเต็มจอ ปิดได้ด้วยปุ่มปิด กด Escape หรือคลิกบริเวณนอกภาพ

## อธิบาย `styles.css`

### ค่าสีและฟอนต์ `:root`

ตัวแปร CSS ด้านบนเก็บสีหลักของธีมทะเล เช่น สีกรมท่า สีเขียวน้ำทะเล สีพื้นหลัง และฟอนต์ เพื่อให้ปรับสีหลักได้จากจุดเดียว

- `--thai` ใช้ฟอนต์ Anuphan สำหรับภาษาไทย
- `--sans` ใช้ฟอนต์ DM Sans สำหรับข้อความอังกฤษ ตัวเลข และป้ายสั้น

### รูปแบบส่วนต่าง ๆ

- `.topbar`, `.brand-logo`, `.nav-links` — แถบเมนูและขนาดโลโก้
- `.hero`, `.hero-photo`, `.hero-shade`, `.hero-content` — ภาพและข้อความแบนเนอร์หน้าแรก
- `.section-wrap`, `.intro`, `.section-heading` — ความกว้างและระยะห่างของส่วนเนื้อหา
- `.villa-grid`, `.villa-card`, `.villa-image`, `.villa-info` — ตารางและรายละเอียดการ์ดบ้านพัก
- `.amenities`, `.amenity-photo`, `.amenity-copy` — ส่วนภาพกับสิ่งอำนวยความสะดวก
- `.notes-grid` — รายการข้อมูลก่อนเข้าพัก
- `.booking`, `.contact-card` — แถบช่องทางติดต่อและปุ่มจอง
- `.modal` — พื้นหลังและขนาดหน้าต่างดูภาพประกาศ

### การรองรับมือถือ

กฎ `@media (max-width: 900px)` และ `@media (max-width: 620px)` ปรับขนาดและเรียงองค์ประกอบใหม่ตามความกว้างจอ เช่น เปลี่ยนการ์ดบ้านพักจาก 3 คอลัมน์เป็น 1 คอลัมน์ และใช้เมนูแบบเปิด/ปิดบนมือถือ

## อธิบาย `script.js`

1. **สลับภาษา** — อ่านข้อความจาก `data-th` และ `data-en` ขององค์ประกอบ แล้วเปลี่ยน `lang` ของเอกสารด้วย
2. **เมนูมือถือ** — เพิ่มหรือลบคลาส `show` เพื่อเปิด/ปิดเมนู และอัปเดตสถานะ `aria-expanded`
3. **ปีลิขสิทธิ์** — ใส่ปีปัจจุบันในองค์ประกอบที่มี `id="year"`
4. **ดูภาพประกาศ** — ปุ่มที่มี `data-poster` เปิดไฟล์ภาพเต็มใน `posterModal`; ขณะเปิดจะล็อกการเลื่อนหน้าเว็บและย้ายโฟกัสไปปุ่มปิด เมื่อปิดจะคืนโฟกัสกลับไปยังปุ่มเดิม

## จุดที่มักแก้ไข

- เปลี่ยนข้อความหน้าเว็บ: แก้ข้อความภายในองค์ประกอบใน `index.html` และแก้ทั้ง `data-th` กับ `data-en` เพื่อให้สองภาษาตรงกัน
- เปลี่ยนราคา/จำนวนห้อง/จำนวนผู้เข้าพัก: แก้ข้อมูลใน `.villa-info` ของการ์ดหลังนั้น
- เปลี่ยนรูปหน้าแรก: วางรูปใหม่ใน `assets/` แล้วแก้ URL ในกฎ `.hero-photo` ใน `styles.css`
- เปลี่ยนรูปปกการ์ด: แก้ URL ของ `.image-a`, `.image-b` หรือ `.image-c` ใน `styles.css`
- เปลี่ยนภาพประกาศเต็ม: แก้ค่า `data-poster` ใน `index.html` และเก็บไฟล์รูปไว้ในตำแหน่งที่ URL นั้นอ้างถึง
- เปลี่ยนโลโก้: แทนที่ `assets/indigo-logo.png` หรือแก้ `src` ของรูป `.brand-logo`
- เปลี่ยนขนาดโลโก้: ปรับ `width` ใน `.brand-logo` และกฎมือถือท้ายไฟล์ CSS
- เปลี่ยนช่องทางติดต่อ: แก้ URL LINE และหมายเลขในลิงก์ `tel:` ภายในส่วน `#contact`
- ปรับตำแหน่งหรือสี: แก้กฎ CSS ของคลาสส่วนนั้น โดยค่าสีรวมอยู่ด้านบนใน `:root`
