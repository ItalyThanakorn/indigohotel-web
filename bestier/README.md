# Bestier website — แก้อะไรที่ไหน

| ต้องการแก้ | ไฟล์ |
|---|---|
| ชื่อ โลโก้ ที่อยู่ เบอร์ LINE WhatsApp Facebook แผนที่ โปรโมชัน ลิงก์ OTA | `js/config.js` → `SITE` |
| สิ่งอำนวยความสะดวก, ที่ใกล้เคียง, สาขาในเครือ, แกลเลอรี, นโยบายเข้าพัก | `js/config.js` |
| ห้องพัก (ชื่อ ราคาเริ่มต้น เตียง รูป สิ่งอำนวยความสะดวก) | `js/rooms.js` → `ROOMS` |
| ข้อความ TH/EN ที่เหลือทั้งหมด | `js/language.js` → `DICT` |
| เมนู, Header, Footer, ปุ่มติดต่อด่วน | `js/navigation.js` |
| สี ขนาดตัวอักษร ฟอนต์ รูป hero แต่ละหน้า | `css/style.css` (`:root` และ `.page-hero--*`) |

หลักการ: ข้อมูลอยู่ใน `js/` ไม่ต้องแตะ HTML — เพิ่มห้อง/สาขา/ภาพ = เพิ่มหนึ่งบล็อกใน array.
ฟอร์มสอบถามและฟอร์มติดต่อสร้างข้อความแล้วเปิดแชท LINE OA (ไม่ต้องมี backend).
