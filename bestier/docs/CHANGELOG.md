# Changelog

## Bestier front-end delivery

- Established the gold, indigo and ivory design system with scoped design tokens.
- Documented the architecture, component behavior and implementation plan.
- Built four responsive static pages in Thai and English.
- Added saved language preference, room photo lightbox, mobile navigation, policy disclosures and back-to-top interaction.
- Added room, facility, location, contact, arrival and policy information from the supplied hotel content.
- Added locally hosted Noto Serif (including Thai glyph coverage) and Kanit font files, shared type-role classes and a global text-size token.
- Added QA results and developer handover documents.
- Added a content clarity audit that lists missing or ambiguous hotel details without inventing answers.

## Current known limitations

- No booking, payment, prices, live room inventory, database or backend.
- Production domain and host are not yet specified.
- Cross-browser/device coverage and external URL ownership checks remain for release.
- Hotel confirmation is needed for the late check-out fee boundary and smoking-fee currency.
